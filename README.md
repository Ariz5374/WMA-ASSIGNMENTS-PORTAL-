# WMA Assignment Portal

Assignments from the SMIT Modern Web Development Application course.
`index.html` is the portal; each project lives in its own folder.

## Go live with GitHub Pages

1. Create a new repository on GitHub (for example `wma-assignments`).
2. Upload everything in this folder so that `index.html` sits at the repository root.
3. Open **Settings > Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/wma-assignments/`.

## Add a new assignment

1. Copy the project folder in. Use lowercase names with hyphens, no spaces and no `#`.
2. Copy an `<article class="project">` block in `index.html` and change the folder name, title and description.

## Notes

- Folder and file names are case-sensitive on GitHub Pages. `Porshce.jfif` must be written exactly that way in your HTML.
- The Angeethi and social-card pages load fonts, icons and photos from the internet, so they need a connection to look right.
